19. Developer Rules (WAJIB)

Bagian ini menurut saya sangat penting agar Gravity tidak mengulang kesalahan saat implementasi.

Tidak boleh mengubah Design Language utama.
Tidak boleh mengubah struktur Progressive Dashboard.
Tidak boleh membuat Wizard.
Tidak boleh membuat Popup bertingkat.
Tidak boleh mengubah layout utama tanpa persetujuan.
Semua panel menggunakan Internal Scroll, bukan Root Scroll.
Preview harus selalu berukuran 16:9 dan menjadi fokus utama.
Project Summary menggantikan Runtime Monitor.
UI harus responsif terhadap resolusi desktop tanpa menyisakan ruang kosong yang tidak perlu (Adaptive Fill Layout).
Backend harus dipisahkan dari UI. Business logic, service, state management, event, API contract, dan engine tidak boleh bergantung pada tampilan.
Seluruh tombol UI harus terhubung ke action yang jelas dan konsisten sehingga saat backend dibuat tidak terjadi perbedaan nama fungsi, event, atau state antara frontend dan backend.
