# MediaFactory Project Bible v1.0

# 02_ARCHITECTURE_LOCK.md

Version: 1.0

Status: LOCKED

This document defines every permanent architectural decision in MediaFactory.

All future implementations MUST comply with these rules.

No redesign is permitted unless a new Architecture Revision is explicitly approved.

---

# Global Architecture Rules

## AR-001

Reuse First

Before creating a new engine or service, verify that the existing architecture cannot be extended safely.

---

## AR-002

Single Source of Truth

Every domain has exactly one owner.

No duplicate implementations.

---

## AR-003

Renderer Rule

Renderers only draw.

They never:

* analyze
* calculate layouts
* generate presets
* detect beats
* animate
* store state

---

## AR-004

Engine Rule

Engines generate data.

They never render UI.

---

## AR-005

Preset Rule

Presets contain configuration only.

No calculations.

No runtime state.

---

## AR-006

Registry Rule

Registries own lifecycle.

They register, unregister and dispatch modules.

---

## AR-007

Adapter Rule

Adapters connect independent systems.

Adapters never own business logic.
