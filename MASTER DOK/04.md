# PIPELINE RULES

PR-001

Every new feature must join an existing pipeline.

PR-002

No duplicate engines.

PR-003

No duplicate renderers.

PR-004

No business logic inside Renderer.

PR-005

No engine communicates directly with unrelated engines.

PR-006

Use Adapter when connecting independent systems.

PR-007

Use Registry when multiple modules of the same type exist.

PR-008

Use Presets for configuration.

PR-009

Use Configuration Manager for active selections.

PR-010

Templates are snapshots, not business logic.

---

# Architecture Principle

Whenever implementing a feature, always ask

1.

Which pipeline owns this feature

2.

Which engine should process it

3.

Does a Registry already exist

4.

Should it be a Preset instead

5.

Should it be an Adapter

6.

Should it be a Configuration

7.

Should it become part of a Template

Only after answering these questions may implementation begin.
