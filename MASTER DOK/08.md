This document defines the official AI development workflow used throughout MediaFactory.

Every AI assistant must follow these rules before making architectural or implementation decisions.

--------------------------------------------------

# AI ROLES

There are three distinct roles.

--------------------------------------------------

Chief Software Architect

Responsibilities

• Analyze architecture

• Review implementation

• Design pipelines

• Lock architecture

• Plan roadmap

• Prevent technical debt

Never directly rewrite architecture without review.

--------------------------------------------------

Implementation Engineer

Responsibilities

• Implement approved designs

• Modify code

• Create components

• Run build

• Produce implementation reports

Never redesign architecture.

--------------------------------------------------

QA Engineer

Responsibilities

• Manual testing

• Regression testing

• Acceptance verification

• Production validation

QA never changes architecture.

--------------------------------------------------

# WHEN TO CREATE AN ENGINE

Create a new Engine only if

The feature owns runtime logic

Requires independent lifecycle

Produces reusable state

Is consumed by multiple modules

Otherwise

Do not create an Engine.

--------------------------------------------------

# WHEN TO CREATE A REGISTRY

Use a Registry when

Multiple implementations share one interface.

Examples

Animation Registry

Effect Registry

Future

Visualizer Registry

Transition Registry

Plugin Registry

--------------------------------------------------

# WHEN TO CREATE AN ADAPTER

Use an Adapter when

Two independent systems must communicate.

Examples

Beat

↓

Subtitle

Media

↓

Playback

Browser

↓

Channel

Adapters never own business logic.

--------------------------------------------------

# WHEN TO CREATE PRESETS

Use Presets when

Only configuration changes.

Presets never contain

State

Logic

Calculations

Timers

Runtime data

--------------------------------------------------

# WHEN TO CREATE CONFIGURATION

Configuration stores

Current user selections.

Example

Current Typography Theme

Current Reactive Preset

Current Subtitle Animation

Configuration never stores logic.

--------------------------------------------------

# WHEN TO CREATE TEMPLATES

Templates are snapshots.

Templates contain

Configuration

Objects

Workspace

Metadata

Templates never contain

Engines

Runtime state

Active timers

--------------------------------------------------

# RENDERER RULES

Renderer responsibilities

Draw UI

Consume normalized objects

Nothing else

Renderers never

Analyze

Animate

Calculate layouts

Read AudioContext

Store runtime state

--------------------------------------------------

# ENGINE RULES

Engines

Generate runtime state.

Never

Render

Touch React UI

Access unrelated engines

--------------------------------------------------

# IMPLEMENTATION RULES
