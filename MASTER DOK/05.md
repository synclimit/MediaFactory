# MediaFactory Project Bible v1.0

# 05_OBJECT_MODELS.md

Version: 1.0

Status: LOCKED

Purpose

Define every core object used throughout MediaFactory.

Every module must use these schemas.

Creating duplicate object structures is prohibited.

---

# OBJECT PHILOSOPHY

Everything inside MediaFactory is an object.

Objects are immutable data contracts.

Renderers consume objects.

Engines transform objects.

Templates save objects.

Nothing bypasses object models.

---

# Object Rules

OM-001

Never duplicate objects.

OM-002

Every object has one owner.

OM-003

Renderers consume objects.

OM-004

Engines transform objects.

OM-005

Templates serialize objects.

OM-006

Objects remain immutable whenever possible.

OM-007

Future extensions must extend existing schemas instead of replacing them.
