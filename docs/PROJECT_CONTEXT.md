# Project Context: MediaFactory

## Overview
MediaFactory is a desktop-first, offline-first, local automation platform designed for playlist video production. It provides a creator-focused, beginner-friendly, and stability-first environment to automate repetitive media compilation tasks using FFmpeg.

## Target Audience
- Reggae creators
- Lofi creators
- Rain ambience creators
- Music playlist creators
- Faceless YouTube creators

## Core Workflow Principle
Input Assets → Queue → Render → Validation → AutoUploader

## Product Boundaries
### In-Scope Focus
- Local desktop-first application execution.
- Offline-first operation (no internet required for video compilation).
- Queue-based processing for batch automation.
- Automated local rendering with FFmpeg.
- Output validation checks.
- Post-process auto-uploading via configured bridges.

### Out-of-Scope (Explicit Non-Goals)
- **Timeline editing**: No video track trimming, visual keyframing, multi-track cutting, or interactive audio syncing interfaces.
- **Cloud rendering**: No remote servers or SaaS execution environments.
- **AI video generation**: No neural-network-based video synthesis or generative text-to-video AI.
- **Enterprise SaaS**: No subscription modules, team collaboration tools, or cloud tenant databases.
